# 车身"高度/厚度" —— 几何 + 光照双修

## L 的判断
> 「我觉得是上壳太接近透明了，导致看起来毫无厚度」
> 「无论你说破天，这车高度就是扁」

**两个判断都成立，而且是两个独立问题。**

---

## 问题一：几何 —— 车身底板太高，侧壁太矮

### 数据
| 指标 | 改前 | 改后 | 真实 Roadster 2 |
|---|---|---|---|
| 车身底板 yBot（座舱） | 0.412 | **0.232** | — |
| 平均侧壁高度 | 0.501m | **0.677m (+35.3%)** | — |
| 侧壁占车高 | 45.1% | **61.0%** | ~73% |
| 车轮露出占轮径 | 64% | **37%** | 35~40% ✓ |

**关键矛盾**：`magContact = 0.385` 是**磁吸盘贴合面**（车底外挂件），不是车身底板。
底板压到 0.232 后，磁吸盘（半径 0.78m）会露在车壳下方 —— 这正是磁吸车该有的样子。

### 改动
`BODY_SECTIONS` 全部 16 节的 yBot 下探 0.385~0.545 → **0.218~0.345**，
`yTop` 一律不动（车高仍是官方 1.110m，低趴比例保留）。

配套附件全部重新定位：
- 轮拱：中心 0.282→**0.230**，半径 0.330→**0.385**（拱顶仍 0.615 > 轮胎顶 0.600）
- 侧裙：改用 `bodyYBotAt(0.05)+0.055` 动态贴新下沿
- 前脸（灯带/格栅/前唇）、车尾（尾灯/饰板/扩散竖条）按新端面下移
- 车底件：扩散器 0.442→0.250、后喷口 0.410→0.300；**磁吸盘保持 0.395 不动**（magContact 基准）

## 问题二：光照 —— 侧壁接不到任何光

### 关键认知
**车身侧壁的法线朝【水平方向】**，而 `key`/`rim`/`hemi` 全在**上方或斜上方**。
→ 侧壁几乎接不到任何光 → 下半部死黑
→ 上半部被 key 灯直射 → 顶盖一片死白
→ **上白下黑 + 中间无过渡 = 看起来像一张没有厚度的膜**

### 改动
| 参数 | 改前 | 改后 | 作用 |
|---|---|---|---|
| **新增 `sideShape`** | — | **4.0** | **侧向塑形光**：车身局部 +Z、略高于腰线，在车侧压出上亮下暗的渐变带 |
| `key` | 700→420→**180** | | 顶盖不再爆白 |
| `rim` | 520→340→**200** | | 轮廓光同样避免溢出 |
| `carFill` | 0.38→1.05→**1.60** | | 跟车补光，方向改到车腰以下 |
| `hemi` | 0.40→0.70→**1.35** | | groundColor 0x090c12→**0x4a5f78**（下半部朝下，只吃 groundColor） |
| `fill` | 0.48→0.95→**1.25** | | 场景补光 |
| `paint.color` | 0xc8d2dc→0x8fa2b4→**0xbcc6d2** | | 太亮会溢出死白；有侧向光兜底后调回接近白 |
| `paint.clearcoat` | 0.70→**0.45** | | 高光有"往下压"的空间 |
| `paint.roughness` | 0.30→**0.40** | | 同上 |
| `paint.envMapIntensity` | 0.95→**0.85** | | 环境光不再抹平 |

---

## 排查过程中排除的假设（都做了 A/B）

- ❌ **环境贴图太均匀**（RoomEnvironment）：envMapIntensity 0.95→0.25 对 sd 影响 <0.002
- ❌ **clearcoat 太高**：单独降到 0.35/0.20 车身直接全黑 → 亮度几乎全靠镜面
- ❌ **roughness 太高**：提到 0.55/0.70 同样变黑 → 模糊的环境反射变暗
- ❌ **半球光不够**：0.4→8.0 几乎无变化（贡献极小）
- ✅ **`key` 太强**：单独把 700→100，顶盖立刻从死白变成有渐变的曲面 → **锁定根因**
- ✅ **侧壁法线朝水平**：加侧向光立刻出现上亮下暗渐变 → **锁定第二个根因**

## 工具

- `tests/height-check.mjs <tag>` —— 纯背景纯侧视，量车身高度
- `tests/shape-ab.mjs` —— 材质/光照 A/B 框架
- `tests/mat-ab.mjs` —— 车漆参数 A/B 框架

**A/B 框架的三个坑**（都踩过）：
1. 每个变体**独立加载页面** —— 否则状态污染，前一个变体的设置会带进下一个
2. 必须**先 `seek` 再 `advanceFrames` 再取车身位置**算相机 —— 否则车跑出画面
3. 正交相机在此场景 `lookAt` 后朝向异常，**用透视相机**代替
