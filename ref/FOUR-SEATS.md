# 四个座椅 —— 2+2 布局

## L 的需求
> 「都做到这一步了，四个座椅也都整上吧」

## 为什么加
B 柱把车顶分成前后两块风挡后, 座舱结构已经成立, 但里面是**空的**。
透过天幕看下去只有两个黑盒子(座舱井壁), 读感是"箱子"不是"舱"。
四个座椅能让座舱**有内容** —— 从车顶看下去是 2+2 的座椅布局。

## 空间约束(为什么座椅这么矮)
| 位置 | y |
|---|---|
| 座舱地板(井底) | 0.585 |
| 井口 / 玻璃下沿 | 0.845 |
| 车顶 yTop | 1.110 |
| 玻璃面(GLASS_SINK+RISE) | ≈ 1.052 |

真实比例座椅(坐垫+靠背)约 0.62m 高, 净空只有 0.22m → **塞不下**。
=> 座椅【做矮】: 坐垫 0.10 + 靠背 0.22, 只露靠背和头枕顶部。
这正是真实车从外面看座舱的样子。

## 布局
```
        前排 (x=-0.42)          后排 (x=+0.38)
     z=+0.235  z=-0.235      z=+0.215  z=-0.215
   ┌──────────┬──────────┐  ┌──────────┬──────────┐
   │  座椅    │  座椅    │  │  座椅    │  座椅    │
   └──────────┴──────────┘  └──────────┴──────────┘
        ← 前风挡 →   B柱   ← 后风挡 →   行李厢 →
```
- 前排靠背到 x=-0.23, 与 B 柱前沿 0.028 留 0.26 间隙
- 后排靠背到 x=+0.55, 与玻璃后沿 0.78 留 0.23 → 后方是行李厢
- 靠背后倾 15°(0.26 rad) —— "斜"是座椅刚性感的关键
- 头枕单独用更亮的材质 —— 座椅最强的识别特征

## 🔥 踩坑:那个"黑盒子"不是井壁, 是地板
排查花了三轮:
1. 先猜是井壁 → 拆矮(0.16→0.05)→ 黑盒子还在
2. 再猜是座椅 → 调座椅高度倾角 → 黑盒子还在
3. **用逐个隐藏法 + 节点清单定位** → 节点 5-13 是井壁, 102 是磁吸盘
   → 真凶是**地板板**: `floor.position = wallY - depth - 0.01`,
   depth 缩到 0.05 后地板跑到 y=0.785, **整个盖在座椅上面**(坐垫顶才 0.70)

> **"看起来像 X" 时不要一直调 X。** 先用逐个隐藏法定位到底是哪个节点。
> 我连着改了两轮"井壁"和"座椅", 全是盲猜。

## 🔥 踩坑:地板分两半 → 磁吸环穿帮
地板原本分两块给 B 柱"让位", 中间 x=0.10 的缺口**正好是磁吸盘位置**
→ 青色磁吸环从缝里露出来。
解法: 地板改成**一整块**; B 柱的让位靠**玻璃断开**实现, 不需要地板也断。

## 地板宽度必须 > 磁吸环外径
磁吸环 Torus 外径 = 0.44 + 0.036 = **0.476**。
地板半宽必须大于它, 否则环从地板边缘探出来:
- wz=0.90 (半宽 0.45) → 露
- wz=1.02 (半宽 0.51) → 仍露一点
- **wz=1.10 (半宽 0.55) → 挡住 ✓**

## A/B: 玻璃透光度对座椅可见性的影响
| opacity | 效果 |
|---|---|
| **1.0** | **座椅剪影最清晰** ✓ |
| 0.90 | 略糊 |
| 0.82 | 反射开始盖住 |
| 0.72 | 看不清, 且玻璃发灰 |

**结论: 保持完全不透明**(也符合 L 早前"最多 25% 透明"的要求)。
座舱靠**座椅顶出玻璃轮廓**来读, 不靠透视。

## 改动清单
1. `buildSeat(x, z, isRear, mats)` —— 坐垫 + 靠背 + 头枕
2. 材质 `seatMat` / `seatBackMat` / `headrestMat` / `cabinTrim`
3. 座舱地板**一整块** 1.44 × 0.05 × 1.10, 位置 y=0.585-0.025
4. 井壁改成 0.06 高的贴地舱沿矮边
5. 玻璃回到 `opacity: 1.0, transparent: false`
6. 前排座椅 x -0.34 → -0.42

## ⚠️ 踩坑:材质作用域
`buildSeat` 是**模块级函数**, 拿不到 `buildCar()` 里的局部 const 材质
→ 页面初始化直接抛错(`waitForFunction` 超时 30s, 报出来只说"超时", 看不到根因)。
修法: 材质作为参数传入 `{ seatMat, seatBackMat, headrestMat }`。
