# 车顶"厚度感" —— 从"调颜色"到"改结构"

## L 的三次反馈
1. 「上壳太接近透明了，导致看起来毫无厚度」
2. 「无论你说破天，这车高度就是扁」
3. 「**我肉眼看差异也就5%内吧。。。，帮我扩大到70%以上**」

第 3 次是关键 —— 前两轮我把力气全花在**材质和光照**上，
而 L 要的"厚度"是**结构问题**：车顶没有开口，玻璃只是贴在一条白弧上。

---

## 真正的诊断

### 旧车顶的结构
```
CAR_RING 顶部:  tw0.80 半宽0.925  y=0.934
                tw0.90 半宽0.756  y=1.022
                tw0.96 半宽0.468  y=1.075
                tw1.00 半宽0.000  y=1.110   <- 收成一条脊
玻璃:            z=±hw*0.50=±0.497  y=yTop+0.038  <- 浮在这条白弧之上
```
→ 侧视看到的是**一条光滑的白弧**，中间贴了块深色板
→ 无论玻璃多不透明、灯怎么打，都读不出厚度

### 真实车
车顶是**开口**，玻璃嵌在开口里：
- 两侧留白色肩线（A 柱 / 后肩）
- 玻璃边缘**低于**肩线 → 形成一道**暗影凹槽**
- 玻璃有**实体侧壁** → 侧视能看到一条有厚度的边

**厚度感 = 凹槽暗影，不是"看不穿"。** 这一点我前两轮完全没抓住。

## 改动

### 1. 车身顶盖在玻璃区下沉成开口
```js
const GLASS_DROP = 0.105;
// buildBodyShell() 里, 玻璃覆盖的 x 区间内 tw>0.55 的部分整体下压
if (inGlass && tw > 0.55) {
  const k = (tw - 0.55) / 0.45;
  y -= GLASS_DROP * k;
}
```
→ 白色肩线保留在两侧，中间形成开口

### 2. 玻璃下沉 + 实体裙边 + 密封框
```js
const GLASS_SINK = 0.088;   // 边缘相对 yTop 下沉
const GLASS_W   = 0.46;     // 半宽系数(肩部 0.470, 留细框)
const GLASS_RISE = 0.030;   // 中脊比边缘高
```
- `buildGlassCanopy()` 只做上表面
- 新增 `buildGlassRim()`：沿玻璃左右边缘向下的**实体裙边**，用 `darkTrim` 渲染
  → 与玻璃面分成两个 mesh，才能读出"厚度"

### 3. 座舱内衬（带井壁的深色井）
车顶开口后视线会一路看到车底（磁吸盘 y=0.395）。
```js
const wx=1.40, wz=0.98, depth=0.46, wallY=0.845;
// 井底 + 四面井壁
```
**有壁才有"深"的读感** —— 单纯一块板仍会看到底盘。
（试过只放薄板 → 变成烟囱状圆柱；试过盖满开口 → 座舱变成一大块黑，层次全丢）

### 4. 磁吸盘缩小
半径 0.78 → **0.44**（小于玻璃覆盖半宽 0.497），
magRing 0.78→0.44，内圈 0.28+k*0.20 → 0.16+k*0.11。
底板下探后磁吸盘被包在车壳内，半径超玻璃覆盖范围就会从顶视穿帮。

### 5. 玻璃材质（上一轮已做）
`transmission: 0` + `opacity: 1.0` —— transmission 是物理透射，会绕过 opacity，
只降 opacity 没用（实测 0.35/0.25 反而发白）。

## 量化结果

在 demo 跟车镜头（`ref/body-after/` vs `ref/body-v9/`）的车顶区域采样：

| 指标 | before | after | 变化 |
|---|---|---|---|
| **明暗交替次数/线** | 0.31 | **4.24** | **+13.7×** |
| 暗像素占比 | 92.6% | 83.0% | 白色主体占比上升 |

**明暗交替次数**是"厚度感"最直接的信号：
0.31 次 = 一条平缓的白弧；4.24 次 = 肩线/凹槽/玻璃/立柱的多层结构。
