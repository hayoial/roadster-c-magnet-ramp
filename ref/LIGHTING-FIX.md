# 车漆"上壳透明感" —— 光照根因与最小修复

## L 的判断
> 「我觉得是上壳太接近透明了，导致看起来毫无厚度」

**判断正确。** 但"透明"不是材质 alpha 问题 —— 是**高光溢出 + 明暗断层**造成的视觉等价物。

## 实测根因

### 现象（纯侧视轮廓图）
- 车顶/座舱 = **一整片死白**（几乎 255）
- 腰线以下 = **完全死黑**
- 中间**没有任何过渡带** → 曲面只剩两个值 → 视觉上就是一张没有厚度的膜

### 根因：主光与补光相差 1800 倍

| 灯 | 改前强度 | 作用 |
|---|---|---|
| `key` SpotLight | **700** | 从上方直射 → 顶盖被打爆成纯白，高光溢出后曲面细节全丢 |
| `rim` SpotLight | **520** | 后上方轮廓光，同样溢出 |
| `fill` DirectionalLight | 0.48 | 场景补光 |
| `carFill` DirectionalLight | **0.38** | 专门给车用的跟车补光 —— 却只有主光的 1/1800 |
| `hemi` HemisphereLight | 0.40 | 半球环境光 |

单灯 700 打亮车顶 + 补光 0.38 照不到腰线以下 → **上白下黑，中间无过渡**。

### 排除掉的假设
- ❌ **环境贴图太均匀**（RoomEnvironment）—— A/B 显示 envMapIntensity 0.95→0.25 对 sd 影响 < 0.002
- ❌ **clearcoat 太高** —— 降到 0.35/0.20 车身直接变全黑（只剩几条高光线），说明亮度几乎全靠镜面
- ❌ **roughness 太高** —— 提到 0.55/0.70 同样变黑（模糊的环境反射变暗）
- ❌ **半球光不够** —— 0.4→8.0 几乎无变化（这个场景半球光贡献极小）

> 关键单变量实验：只把 `key` 700→100，顶盖立刻从死白变成有渐变的曲面。
> **这一条锁定了根因。**

## 最小必要修复（6 个参数）

```js
key      700 → 420    // 顶盖不再被打爆, 曲面细节回来
rim      520 → 340    // 轮廓光同样避免溢出
fill   0.48 → 0.95    // 场景补光
carFill 0.38 → 1.05   // 跟车补光, 专提亮车身下半部
hemi    0.40 → 0.70   // 环境底光
paint.envMapIntensity 0.95 → 0.72  // 环境光不再把车身抹平
```

**没动的东西**：车身几何、相机、时间轴、喷口、bloom、曝光 —— 一律不碰。

## 效果

demo 三镜头前后对比（`ref/body-fix/` vs `ref/body-light/`）：
- **跟车**：车顶从一整片死白 → 座舱玻璃/顶盖棱线/侧腰转折都能看出来
- **LOW HERO 倒挂**：车身层次分明，能看出侧面/底部/顶部的空间关系
- **喷气**：喷口周围车身的曲面过渡清晰，喷流不再像从"白纸片"里冒出来

量化（喷气镜头车身区灰度标准差）：**0.0508 → 0.0553 (+9%)** —— 明暗层次增加。
