# 座舱布局修正 —— 座椅不再挤在车身中间

## L 的反馈
> 「谁家座椅集中在车身中间啊？」

**完全正确。** 上一轮我只挪了座椅位置，**没动玻璃开口范围**。

## 根因

玻璃开口 `GLASS_X0/GLASS_X1` 只有 `[-0.62, 0.78]` = **1.40m**，
而车身全长 4.42m。四个座位只能全塞在这 1.40m 里面 → 视觉上全部堆在车身正中。

**最打脸的地方**：`BODY_SECTIONS` 的注释本来就写着
「风挡根部 x=-0.700」「车尾玻璃起 x=0.900」——
**设计意图一直是对的，是我实现时把玻璃区缩到 [-0.62, 0.78] 把它埋了。**

## 真实 Roadster 2 布局（反推基准）
```
全长 4.42m, 局部 x: -2.21(鼻) ~ +2.21(尾)
  前舱盖(frunk)   x -2.21 ~ -0.75
  前风挡根部      x ≈ -0.75
  座舱(4座)      x -0.75 ~ +0.95     ← 1.70m
  后风挡/行李厢  x +0.95 ~ +1.9
  尾部           x +1.9 ~ +2.21
```

## 最终参数
| 项 | 改前 | 改后 | 依据 |
|---|---|---|---|
| 玻璃开口 | [-0.62, 0.78] (1.40m) | **[-0.75, 0.95] (1.70m)** | 对齐 BODY_SECTIONS 注释 |
| B 柱 x | 0.10 | **0.22** | 在两排座椅之间 |
| 前排座椅 x | -0.42 | **-0.26** | 靠背到 -0.07，距 B 柱前沿 0.148 有 0.22 |
| 后排座椅 x | +0.38 | **+0.68** | 靠背到 +0.84，距玻璃后沿 0.95 有 0.11 |
| 地板长度 | 1.44 | **1.72** | 覆盖整个开口 |
| 地板中心 | 0.08 | **0.10** | 开口中心 |
| 舱沿矮边 | 1.44 | **1.72** | 同上 |

## 中间试错（两次）
1. **开口扩到 [-1.05, 0.90] + B柱 -0.05** → 前风挡变成一大块平板玻璃，
   后舱过长、前舱空旷。**前风挡比后窗长 = 比例错了**
   （真实车是前短后长：后玻璃盖到行李厢）
2. **B柱前移到 -0.05** → 后舱被拉长，B 柱偏前不像话

## 教训
> **改布局时,开口范围和内容物位置必须一起改。**
> 只挪座椅不改开口 = 座椅无处可去, 只能挤在中间。
> 而且 **BODY_SECTIONS 里的注释是现成的设计意图** ——
> 实现前先读注释,别自己另定一套。
