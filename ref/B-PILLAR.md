# 四支柱刚性结构 —— B 柱横梁

## L 的需求
> 「最好还能体现一点点车身刚性四支柱结构的感觉」

## 为什么需要这个
上一轮把车顶改成"下沉开口 + 嵌入式玻璃"后, 厚度感上来了(+13.7×),
但车顶仍是一整块连续天幕 —— 读起来像"蒙了块软布在车顶上", 缺少**结构感**。

真实 Roadster 2 的车顶是**双圆顶 + 中柱**: 一根 B 柱把前后风挡分开,
加上两侧的 A 柱 / C 柱(车身肩线自带), 组成**四支柱拱形结构**。
四支柱的"拱"读起来就是刚性 —— 车身是一个承力框架, 不是一块壳。

## 方案演进

### 试过 1：让顶盖在 B 柱处不下沉
在 `buildBodyShell` 里对 B 柱范围内的 section 跳过下沉。
→ **失败**：留下的只是一条窄脊(半宽 0.115m 的一道白线),
读起来像"一根细棍插在坑里", 完全不是梁。而且被座舱内衬遮住一部分。

### 试过 2：让 B 柱只做"顶点不下沉"而横跨整个 z
→ **失败**：不成立(顶点不下沉 = 一条脊, 不是横跨的梁)。

### 最终方案：独立 B 柱横梁几何
```js
const B_PILLAR_X  = 0.10;    // 中柱位置(座舱中间)
const B_PILLAR_HW = 0.072;   // 沿 x 的半宽
```
`buildBPillar()` 生成一根**真正架在两个开口之间的实体拱梁**:
- 沿 x 有宽度 0.144m
- 沿 z 横跨整个车顶 (`hw * 0.94`)
- 顶部与车身肩线齐平, 底部形成一道拱形暗影
- 拱形: 中间(车顶中线)最高, 往两侧落到开口边缘 —— 读起来是"梁"不是"板"

**配套改动**:
1. **玻璃在 B 柱处断开**成前后两块(前风挡 / 后风挡)
   —— `buildGlassCanopy()` 与 `buildGlassRim()` 都按同样规则分段,
   保证断口对齐, 不会错位
2. **座舱内衬分两块**(中间给 B 柱让位), 否则内衬会把 B 柱遮住
3. **井壁深度 0.46 → 0.30** —— 刚好盖住磁吸盘即可, 少露出来抢视觉
4. **B 柱单独材质** `0xa8b4c2` —— 与车身同色系但略暗, 区分层次又不抢戏

## 最终车顶结构
```
        A柱              B柱(横梁)           C柱
     (车身肩线)        (独立拱梁)        (车身肩线)
         ║      ┌──────────┐      ║
    ─────╫──────┤ 前风挡   ├──────╫─────
         ║      └──────────┘      ║
         ║   ┌──────────────┐     ║
    ─────╫───┤   后风挡      ├─────╫─────
         ║   └──────────────┘     ║
```
