# 喷口清单 — Tesla Roadster @ C 形坡道倒挂

> 本文档数值与 `outputs/index.html` 的 `NOZZLE_DEFS` 保持同步。
> 校验: `node tests/nozzles.test.mjs` (读取实际配置 + 实际姿态计算结果做物理语义断言)

## 坐标系约定

- 局部 +X = 车长轴, **车头在 −X, 车尾在 +X**
- 局部 +Y = **车顶/甲板方向** (底盘在 −Y 侧)
- 局部 +Z = 车宽轴 (车轮轴)
- 局部原点 = 车辆接地点平面 (车轮半径 0.300, 轮心 y=0.300, 最低点 y=0)

**倒挂姿态下**: 车停在坡道悬臂**下方**, 车顶/甲板朝世界**下方**, 车底朝世界**上方**。
因此 局部 +Y → 世界向下, 局部 −Y → 世界上方。

## 两种推进任务的区分 (P0 修复要点)

### A. 倒挂 / 脱轨 / 翻正 (hang, descent, roll)

主喷流装在**甲板/车顶侧**, 局部轴线朝 +Y。
倒挂时 局部 +Y = 世界下方 → 喷射方向为世界向下, 提供向下的减速推力。

**方向约束**: `updateNozzles()` 读取车辆当前 `up.y`:
- `up.y < 0` (倒挂) → 主喷流全功率, 方向朝下 ✓
- `up.y` 由负转正 (翻正过程) → 强度按 `min(1, -up.y*1.6)` 自然衰减
- `up.y > 0` (已翻正) → 主喷流**停用** (否则会变成朝上的错误推力)

### B. 接近地面的缓降 (cushion)

车底中央单束 `under-core`, 局部轴线朝 −Y。
只在**车已翻正**时激活 —— 此时 局部 −Y = 世界下方, 语义与方向一致。

**`under-core` 绝不能在 `descent` / `roll` 阶段激活**:
车辆仍倒挂时 局部 −Y 指向世界上方, 会变成朝上的错误推力。
(旧实现把它配成 `stage: ['descent','cushion']`, 已在 2026-10-21 修正为 `['cushion']`)

### C. 触地后

`landed` 阶段所有定向喷流停止 (实测 t=11.7s 激活喷流数 = 0),
仅保留扩散白雾表现触地蒸汽云。

## 证据分级

**视频可见事实** (原视频 Run one, C 形坡道段 0-23.5s)
- 20.4s 倒挂: 1 条蓝青光束自车身下部射出, 指向后下方
- 20.8s 2 条 / 21.2s 2 条 / 21.6s 3 条 / 22.0s 3 条 / 22.4s 3-4 条
- 22.4s 起底部开始涌出白色蒸汽; 23.2s 已基本正立, 底部大团蒸汽云
- 量化: 光束质心恒在尾灯亮芯**下方** (dy>0); 白雾像素 2054(20.4s) → 18957(22.4s) → 30524(23.2s)
- 姿态: 12.0s 车头朝左略俯 → 20.4s 车头朝左下 → 23.2s 车头朝下
  (尾部扰流板在画面右上角位置基本不变 → 翻转是**俯仰 nose-down**)

**为实现而采用的合理近似 (视频不可见)**
- 光束具体 3D 坐标与锥角: 视频只能看出"从车身下部、1→4 条、朝后下方", 精确位置不可见
  → 采用甲板侧前中 2x2 对称布置
- 内部推进器结构: 视频为夜间远景, 内部完全不可见 → **不作任何断言**
- 翻正旋转轴: 视频俯视机位不足以直接读出 3D 旋转轴。
  本项目按绕车辆纵轴 180° 横滚实现, 并通过渲染帧逐帧核对车顶朝向序列
  ((0,−1,0) → 侧向 → (0,1,0))。**注意: 视频证据更支持"俯仰 nose-down"**,
  二者未完全一致, 已列入待确认项。
