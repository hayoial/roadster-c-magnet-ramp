# 喷口清单 — Tesla Roadster @ C 形坡道倒挂

## 坐标系约定

- 局部 +X = 车长轴, **车头在 −X, 车尾在 +X**
- 局部 +Y = **车顶方向** (底盘在 −Y 侧)
- 局部 +Z = 车宽轴 (车轮轴)
- 局部原点 = 车辆接地点平面 (车轮半径 0.345, 中心 y=0.345)

**倒挂姿态下**: 车顶朝世界下方, 车底朝世界上方 (车停在坡道悬臂下方)。
因此 局部 +Y → 世界向下, 局部 −Y → 世界向上。

## 各阶段推进任务 (严格区分)

| 阶段 | 时间(原视频) | 动作 | 生效喷口 | 世界方向 |
|------|-------------|------|---------|---------|
| `hang` | 19.6-20.4s | 倒挂吸附, 顶盖侧 2 条蓝束向下 | top-rear-l/r | **向下** (局部 +Y → 世界下) |
| `descent` | 20.4-22.0s | 脱轨下落, 4 条平行蓝束朝下 | top-rear-*, top-mid-* | **向下** |
| `roll` | 22.0-23.0s | 空中翻正, 顶盖侧光束持续 + 侧向姿态喷气 | top-*, attitude-* | 随姿态偏转 |
| `cushion` | 22.5-23.3s | 接近地面, 车底向下缓降 | under-core | **向下** (车已翻正) |
| `landed` | 23.3s+ | 触地, 仅剩扩散白雾 | 无 | - |

## 明确区分的两种推进任务

**A. 脱轨后的姿态恢复 (hang / descent / roll)**
- 顶盖侧 4 束主喷流: 局部 +Y = 世界下方 => 倒挂时向下推, 把车压离坡道并减速
- 左右侧向成对喷口: 局部 ±Z 方向, 用于修正横滚
- 翻正靠绕车辆纵轴 180° 横滚完成, 喷气提供辅助力矩

**B. 接近地面的缓降 (cushion)**
- 车底中央单束: 局部 −Y => 车翻正后即世界向下, 降低下落速度
- 与 A 的顶盖侧喷流**位置和方向都不同**, 形态也不同 (A 是窄平行射流, B 是宽缓降雾流)

## 证据分级

**视频可见事实**
- 19.6-20.0s 倒挂时可见 2 条蓝色光束自车尾/顶盖侧射出, 指向画面左下
- 20.4-21.2s 光束增至 3-4 条, 4 条时呈平行分布
- 光束是窄而平行的定向射流, 非弥散雾团
- 22.5-23.3s 接近地面与触地时底部涌出大量白色蒸汽, 触地时炸成大团
- 19.6s 帧可确认: 车尾贯穿灯亮条在画面上缘, 底盘机械结构在其下方 => 倒挂时车顶朝下

**为实现而采用的合理近似 (视频不可见)**
- 光束具体 3D 坐标与锥角: 视频只能看出"从上部/尾部、4 条、平行朝下", 精确位置不可见 -> 采用车顶前中 2x2 对称布置
- 内部推进器结构: 视频为夜间远景, 内部完全不可见 -> **不作任何断言**
- 翻正旋转轴: 按绕车辆纵轴 180° 实现; 视频俯视机位不足以直接读出 3D 旋转轴, 已通过渲染帧逐帧核对车顶朝向序列 (up: (0,-1,0) -> 侧向 -> (0,1,0))
