# 车身立体感修正 —— 根因与改动

## 症状
车身看起来"像一块很薄的电脑鼠标"：斜侧视角下, 白色车身像一张毯子盖在四个轮子上,
下半部镂空, 轮子光秃秃挂在车底。

## 根因 (四项, 逐个量化)

### 1. 横截面底部是"尖脊"而不是"面"
旧 `CAR_RING` 底板中心 wf 只有 **0.40**, tw 0.07 才到 0.78, tw 0.18 才到 0.94。
→ 车身底部是一根 0.4m 宽的窄脊, 两侧全空
→ 侧腰"实心带"(wf>=0.94)只有 y 0.538~0.901, 共 **0.363m**
→ 从底板(y=0.412)到满宽(y=0.60)是 **49° 大锥面**, 3/4 视角下"透"成薄片

### 2. 车头截面退化成一条线
`BODY_SECTIONS[0] = [-2.210, 0.560, 0.560, 0.640]` —— **yTop == yBot**,
车鼻在数学上就是零厚度的尖点, 侧视是个长喙。
车尾也只剩 0.28m 厚。

### 3. 翼子板没有隆起, 车轮是"插进"车身而非"陷在翼子板里"
轮胎内缘 z=0.861 会插进车身(半宽 0.979), 但车身在轮拱处**平直**,
车轮看起来像硬塞进去的。真实跑车有后肩(rear haunch)和前翼子板隆起。

### 4. 车身下沿与车轮之间没有边界
白色车身直接过渡到黑色轮胎, 没有一条明确的"下沿",
视觉上白色区域就"飘"在轮子上方。

## 改动

### A. `CAR_RING` 9 点 → 10 点, 底部加宽 + 下腰近垂直
```
[0.00, 0.880]  底板中心 (原 0.40) —— 底部是一整块板
[0.02, 0.960]  底板外缘 几乎垂直上收 (斜率约 12°, 原 49°)
[0.10, 0.995]  下腰 (原 tw0.18/0.94) 提前到近满宽
[0.20, 1.000]  侧腰最宽
[0.45, 1.000]  侧腰保持满宽
[0.65, 0.985]  上腰线 (原 0.94)
[0.80, 0.930]  车顶侧缘 (原 tw0.70/0.94) 肩部收窄推迟
[0.90, 0.760] / [0.96, 0.470] / [1.00, 0.100]  顶盖
```
→ 实心带 0.363m → **0.426m (+17%)**

### B. `BODY_SECTIONS` 首尾给真实厚度 + 前后肩隆起
- 车鼻: `yTop 0.560→0.645`, `yBot 0.560→0.500`, `hw 0.640→0.700`
- 尾端: `yTop 0.800→0.830`, `yBot 0.520→0.545`, `hw 0.560→0.660`
- 车头 hw 增长放缓 (0.700→0.820→0.895, 原 0.640→0.790→0.895) —— 不再尖长
- 后肩: x=1.26 `yTop 0.975→1.000` (比座舱只低 0.11m), x=1.62 `0.930→0.955`
- 前翼子板: x=-1.43 `yTop 0.935→0.965`

**车顶最高点 yTop = 1.110 一律不动** —— 低趴跑车比例保留

### C. 新增翼子板隆起 `FENDER_BULGE`
```js
const FENDER_BULGE = [
  { cx: -1.30, amp: 0.082, w: 0.66 },   // 前翼子板
  { cx:  1.38, amp: 0.112, w: 0.72 },   // 后翼子板(更饱满)
];
```
- 高斯型包络, 高度权重只作用在 tw 0.04~0.62 (腰线以下), 车顶不受影响
- `buildBodyShell()` 与 `bodySurfaceZ()` **共用同一个 `fenderBulge()`**
- 新增 `bodyBaseZ()`: 不含 bulge 的半宽, 供 `WHEEL_Z` 使用
  → 否则 bulge 会把轮子一起顶出去, 车身反而罩不住轮胎
- 轮距系数 0.985 → **0.965** (轮心内收, 让鼓出的翼子板正好盖住胎面外缘)

### D. 侧裙加厚并贴合体表下沿
- `BoxGeometry(2.16, 0.105, 0.060)`, 贴在 `bodyYBotAt(0.05) + 0.070`
- 高度受 `magContact = 0.385` 约束 —— **不能下探到磁吸贴合面以下**, 否则插进坡道

## 数值验证

| 项 | before | after | 真实 Roadster 2 |
|---|---|---|---|
| 车身实体高度占比(侧视) | 65.3% | **70.3%** | ~73% |
| 车轮露出占车高 | 34.7% | **29.7%** | ~27% |
| 车身半宽@轮顶 (前) | 0.979 | **1.0695** | 罩住胎面外缘 1.0554 |
| 车身半宽@轮顶 (后) | 0.912 | **1.0620** | 罩住胎面外缘 1.0554 |
| 底板 vs magContact | 0.412 | 0.412 | 不穿坡道 |

## 试过但撤回的方案

**下包围 / rocker 放样裙板**(沿 X 放样的厚裙板, 向下到 `yBot-0.055`)
→ 视觉上确实加厚了下半身, 但会下探到 `magContact(0.385)` 以下 → **插进坡道**
→ 撤回, 改为只做侧裙 (贴在底板上方)
