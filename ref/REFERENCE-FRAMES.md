## 视频可见事实 (可直接观察 + 量化)

1. **光束来自车身下部, 指向后下方**。量化: 光束质心恒在尾灯亮芯**下方** (dy 全部 > 0);
   灯→束连线角 177.9°(20.4s, 近水平向后) → 143.8°(21.6s) → 119.7°(22.4s) → 73.5°(22.8s, 近垂直向下)。
   即光束方向随翻正逐渐转到垂直向下。
2. **光束数量递增**: 1(20.4s) → 2(20.8s) → 3(21.6s) → 3-4(22.4s)。
3. **光束形态**: 窄而平行的定向射流, 非弥散雾团。
4. **白色蒸汽云与定向射流是两种不同的东西**。白雾像素量: 2054(20.4s) → 6753(22.4s)
   → 20147(22.8s) → 30524(23.2s), 触地时爆开成大团。
5. **姿态**: 12.0s 车头朝左略俯 → 20.4s 车头朝左下 → 23.2s 车头朝下。
   尾部扰流板(白色板状件)在画面右上角位置基本不变 → **翻转是俯仰 nose-down**。
6. **车型特征** (12.0s 侧影最清晰): 白色车身 / 大面积深色全景玻璃车顶 / 极低趴楔形车头 /
   贯穿式细灯带 / 黑色轮圈 / 短前后悬 / 车尾短促上扬。

## 为实现动作而采用的合理近似 (非视频可见事实)

- 光束具体 3D 坐标与锥角: 视频只能看出"从车身下部、1→4 条、朝后下方", 精确位置不可见
  → 采用甲板侧前中 2x2 对称布置。
- 内部推进器结构: 视频为夜间远景, 内部完全不可见 → **不作任何断言**。
- 翻正旋转轴: **本项目按绕车辆纵轴 180° 横滚实现**,
  而视频证据(扰流板位置不变 + 车头由朝左转朝下)**更支持俯仰 nose-down**。
  两者未完全一致 → 列入待确认项, 不宣称已还原。
