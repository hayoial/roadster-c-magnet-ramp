## 视频可见事实 (可直接观察)

1. **倒挂时车在坡道悬臂【下方】, 车顶朝下、车底朝上贴住悬臂** —— 19.6s 帧中车尾贯穿灯亮条在画面上缘, 底盘机械结构在其下方。
2. **向下光束来自车【上部/尾部】** —— 19.6-21.2s 可见光束自车尾/顶盖一侧射出, 指向世界下方。
   => 倒挂时 车顶侧法向(局部 +Y) = 世界向下; 车底侧法向(局部 -Y) = 世界向上。
3. **光束数量随阶段增加**: 2 条 (19.6s) -> 3-4 条 (20.4s) -> 4 条平行 (21.4-22.0s)。
4. **光束是窄而平行的定向射流**, 不是弥散雾团。
5. **落地时底部炸开大团白色蒸汽云** (22.5-23.3s) —— 属触地/近地缓冲, 不是喷口射流。
6. **车型特征** (12.0s 侧影最清晰): 白色车身 / 大面积深色全景玻璃车顶 / 极低趴楔形车头 / 贯穿式细灯带 / 黑色轮圈 / 短前后悬 / 车尾短促上扬。

## 为实现动作而采用的合理近似 (非视频可见事实)

- 光束的具体 3D 坐标与锥角: 视频只能看出"从上部/尾部、4 条、平行朝下", 精确位置不可见 -> 采用车顶前中 2x2 对称布置 (2 组共 4 束)。
- 内部推进器结构: 视频为夜间远景, 内部不可见 -> **不作任何断言**。
- 翻正旋转轴: 按"绕车辆纵轴 180°"实现 (与现有运动学一致), 视频俯视机位不足以直接读出 3D 旋转轴, 已在渲染帧中核对车顶朝向序列。
